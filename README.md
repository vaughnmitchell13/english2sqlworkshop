# English to SQL Workshop
Convert natural language to SQL queries using Google AI Studio and the Gemini API. Ask a question, inspect Gemini's response, and run the query against the database.

Data: A Netflix catalog of movies and TV shows. This is prepared for you, nothing to engineer or clean on your end. 
Source: [Hugging Face](https://huggingface.co/datasets/hugginglearners/netflix-shows)

Resources used: Google Colab, Google AI Studio, sqlite3

## Setup
1. Download the `english2sql_WORKSHOP.ipynb` notebook and the `netflix.db` file to your system.
2. Navigate to [Google Colab](https://colab.research.google.com/) and choose `Upload Notebook`. Upload the notebook you just downloaded.
3. We will cover the remaining setup inside that notebook.
